\section{Antes de empezar}
\subsection*{Cómo entras}
\begin{enumerate}
  \item Abre el enlace del correo de Traza FI (por ejemplo, «Voto aprobatorio · nombre del egresado»).
  \item Si tienes cuenta con ese mismo correo, también encuentras tus firmas en \emph{Posgrado: firmas}.
\end{enumerate}
\begin{tencuenta}
\begin{itemize}
  \item El enlace es personal y tiene fecha de vencimiento (se indica en el correo).
  \item Antes de firmar puedes leer el documento completo.
  \item Eres responsable de verificar que las firmas electrónicas del sínodo estén vigentes a la fecha del examen.
  \item Después del examen, sube la tesis al Repositorio Institucional en los tres días siguientes.
\end{itemize}
\end{tencuenta}
\begin{algosalemal}
\begin{itemize}
  \item Si el enlace venció, pide al egresado que te lo reenvíe desde su trámite.
  \item Si el trámite está en pausa, el enlace lo indica y no permite firmar.
  \item Si un dato del documento está mal, no firmes: avisa al egresado para que lo corrija; el documento se genera de nuevo.
\end{itemize}
\end{algosalemal}
