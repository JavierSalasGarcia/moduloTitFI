\section{Subdirector Académico: visión global}
Este manual reúne lo que el actor hace en \textbf{todas} las opciones de titulación y señala, al final, lo particular de cada una. Para el detalle paso a paso de una opción, consulta el manual específico de esa opción.

\subsection{Opciones en las que participa}
\begin{itemize}
  \item Aprovechamiento académico
  \item Examen General de Egreso (EGEL)
  \item Créditos en estudios avanzados
  \item Artículo especializado para publicar en revista indizada
  \item Ensayo
  \item Memoria de experiencia laboral
  \item Reporte de aplicación de conocimientos
  \item Reporte de autoempleo profesional
  \item Reporte de residencia de investigación
  \item Tesina
  \item Tesis
\end{itemize}

\subsection{Pasos comunes}
\begin{enumerate}
  \item Entrar a \emph{Titulación $\rightarrow$ Firmas pendientes}.
  \item Revisar cada formato u oficio (\emph{Ver}) y firmarlo; pueden firmarse seleccionados o todos los pendientes.
  \item La firma estampa un sello electrónico con nombre, cargo, folio y huella; un asistente puede firmar en su nombre.
\end{enumerate}
