\section{Antes de empezar}
\subsection*{Cómo entras}
\begin{enumerate}
  \item Abre el enlace del correo (por ejemplo, «Firma del voto aprobatorio» u «Oficio de citación»).
  \item Con sesión: \emph{Titulación} → \emph{Mis pendientes}.
\end{enumerate}
\begin{tencuenta}
\begin{itemize}
  \item Desde el enlace del oficio puedes descargar el trabajo escrito.
  \item Al firmar de recibido, el examen aparece en tu calendario de Traza FI.
  \item Tus constancias de sinodal aparecen en \emph{Mis constancias}.
\end{itemize}
\end{tencuenta}
\begin{algosalemal}
Si no puedes asistir, avisa cuanto antes a Apoyo a Titulación para que se convoque al suplente.
\end{algosalemal}
