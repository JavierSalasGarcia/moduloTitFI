\section{Antes de empezar}
\subsection*{Cómo entras}
\begin{enumerate}
  \item Abre el enlace del correo que te envía Traza FI (asunto como «Firma de protocolo · TIT-…»).
  \item Para firmar necesitas sesión con el mismo correo al que llegó el enlace; si no tienes cuenta, el enlace te lleva a crearla.
  \item Con sesión, todo lo que te toca está en \emph{Titulación} → \emph{Mis pendientes}.
\end{enumerate}
\begin{tencuenta}
\begin{itemize}
  \item El enlace es personal; no lo compartas.
  \item Antes de firmar puedes leer el documento completo con \boton{Leer el documento (PDF)}.
  \item Tus constancias de asesoría se generan solas y aparecen en \emph{Mis constancias}.
\end{itemize}
\end{tencuenta}
\begin{algosalemal}
\begin{itemize}
  \item Si el enlace venció o no lo encuentras, pide al pasante que te lo reenvíe desde su trámite.
  \item Si el trámite está en pausa, el enlace lo indica y no permite firmar hasta que el pasante lo retome.
\end{itemize}
\end{algosalemal}
