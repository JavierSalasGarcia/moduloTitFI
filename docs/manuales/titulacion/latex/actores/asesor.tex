\section{Asesor}
\subsection{Qué hace el asesor}
\begin{enumerate}
  \item Recibe por correo un enlace personal para dar el Vo.\,Bo. a las solicitudes del pasante (protocolo, revisión, sustentación).
  \item Firma el voto aprobatorio junto con los revisores.
  \item Sus constancias de director se generan solas al avanzar el trámite.
\end{enumerate}
\aviso{Cuentas, correos y datos de los ejemplos son ficticios y provienen de una base de pruebas.}
