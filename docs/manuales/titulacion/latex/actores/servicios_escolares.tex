\section{Servicios Escolares (Administración Central)}
\subsection{Qué recibe Servicios Escolares}
\begin{enumerate}
  \item No usa la plataforma: recibe del Departamento de Titulación una carpeta comprimida por lote.
  \item Cada expediente trae los documentos en el orden del formato de integración, el formato llenado y un índice con la huella SHA-256 de cada archivo.
  \item Con ella se inicia la expedición del título profesional.
\end{enumerate}
\aviso{Cuentas, correos y datos de los ejemplos son ficticios y provienen de una base de pruebas.}
