\section{Antes de empezar}
\subsection*{Cómo entras}
\begin{enumerate}
  \item Recibes la carpeta comprimida (ZIP) que exporta el Departamento de Titulación.
\end{enumerate}
\begin{tencuenta}
\begin{itemize}
  \item Cada expediente trae los documentos numerados en el orden del formato de integración, el formato llenado, el formato de revisión y un índice con la huella SHA-256 de cada archivo.
  \item La huella permite comprobar que ningún archivo cambió después de exportarse.
\end{itemize}
\end{tencuenta}
\begin{algosalemal}
Si falta un documento o una huella no coincide, comunícalo al Departamento de Titulación indicando el folio.
\end{algosalemal}
