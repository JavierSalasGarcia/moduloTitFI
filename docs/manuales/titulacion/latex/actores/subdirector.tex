\section{Antes de empezar}
\subsection*{Cómo entras}
\begin{enumerate}
  \item \emph{Titulación} → \emph{Firmas pendientes}.
\end{enumerate}
\begin{tencuenta}
\begin{itemize}
  \item Antes de firmar puedes abrir la vista previa de cada documento.
  \item Puedes firmar los seleccionados o todos los pendientes con un botón.
  \item La firma estampa un sello con nombre, cargo, folio y huella del documento.
\end{itemize}
\end{tencuenta}
\begin{algosalemal}
Si un documento tiene un error, no lo firmes: avisa a Titulación para que se corrija y se genere de nuevo.
\end{algosalemal}
