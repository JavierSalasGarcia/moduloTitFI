\section{Antes de empezar}
\subsection*{Cómo entras}
\begin{enumerate}
  \item Abre el enlace del correo de Traza FI.
  \item Firma con sesión del mismo correo al que llegó el enlace.
\end{enumerate}
\begin{tencuenta}
\begin{itemize}
  \item El enlace es personal.
  \item Tus constancias de coasesoría se generan solas.
\end{itemize}
\end{tencuenta}
\begin{algosalemal}
Si el enlace venció, pide al pasante que lo reenvíe.
\end{algosalemal}
