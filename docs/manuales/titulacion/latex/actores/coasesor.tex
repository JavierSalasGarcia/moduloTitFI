\section{Coasesor}
\subsection{Qué hace el coasesor}
\begin{enumerate}
  \item Si el protocolo registra coasesoría, recibe el mismo tipo de enlaces que el asesor para los formatos que le corresponden.
  \item Sus constancias de codirector se generan solas al avanzar el trámite.
\end{enumerate}
\aviso{Cuentas, correos y datos de los ejemplos son ficticios y provienen de una base de pruebas.}
