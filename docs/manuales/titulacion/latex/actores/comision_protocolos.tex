\section{Comisión de revisión de protocolos}
\subsection{Qué hace la comisión de revisión de protocolos}
\begin{enumerate}
  \item El encargado de comisión (\emph{Mi comité de revisión}) recibe el protocolo que turnó Titulación y elige a los evaluadores.
  \item Cada evaluador recibe un enlace personal con fecha límite, redacta recomendaciones de forma y fondo y firma.
  \item Con todas las firmas, el encargado consolida y firma el dictamen; el pasante solo ve el dictamen consolidado.
\end{enumerate}
\aviso{Cuentas, correos y datos de los ejemplos son ficticios y provienen de una base de pruebas.}
