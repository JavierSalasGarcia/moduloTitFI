\section{Antes de empezar}
\subsection*{Cómo entras}
\begin{enumerate}
  \item Encargado: \emph{Titulación} → \emph{Mi comité de revisión}.
  \item Evaluadores: \emph{Titulación} → \emph{Protocolos por revisar} (también en \emph{Mis pendientes}).
\end{enumerate}
\begin{tencuenta}
\begin{itemize}
  \item Cada revisión tiene fecha límite (siete días hábiles por omisión); el semáforo indica cuáles van tarde.
  \item El dictamen solo se envía cuando todos los evaluadores firmaron.
\end{itemize}
\end{tencuenta}
\begin{algosalemal}
\begin{itemize}
  \item Si un evaluador no puede revisar, el encargado cancela su asignación y asigna a otra persona.
  \item Si el pasante dejó su trámite en pausa, la revisión queda detenida hasta que lo retome.
\end{itemize}
\end{algosalemal}
